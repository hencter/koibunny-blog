这是一个**纯前端可交互原型**，目的是让需求评审时对方点得动，而不是看截图。
双击 `index.html` 就能跑，不需要装依赖、不需要后端、不连任何 CDN。

## 覆盖的模块

| 模块 | 演示内容 |
| --- | --- |
| 工作台 | 经营 KPI、销售与利润趋势、渠道占比、待办审批、库存预警 |
| 销售管理 | 订单列表与筛选、订单详情、新增订单、报价 / 发货 / 退货 |
| 采购管理 | 采购订单、供应商绩效、采购申请、采购闭环流程 |
| 库存管理 | 多仓库台账、低库存预警、出入库流水、入库登记 |
| 生产制造 | 工单与进度、设备稼动率、BOM 清单、新建工单 |
| 财务管理 | 应收应付、账龄与催收、资金流入流出、开票登记 |
| 报表中心 | 目标达成、品类结构、产品线排行、指标对比 |
| 客户管理 | 客户档案与分级、跟进记录、健康分、新增客户 |
| 人力资源 | 员工花名册、部门出勤率、人事待办、入职登记 |
| 系统设置 | 组织权限、审批流、功能开关、角色权限示例 |

## 两个刻意的取舍

**图表不用图表库。** 所有趋势图、占比图、排行都是内联 SVG 手绘的。
理由是这份原型的生命周期以周计，引入一个图表库就意味着之后每次评审都要带着它升级。
手绘 SVG 丑一点，但它不会因为依赖被弃用而烂掉。

**演示数据集中在一个文件。** 订单、客户、物料全部放在 `assets/app.js` 里，
页面模板与业务数据分离。交给开发团队时，替换这一个文件就是接真实接口的入口，
不需要在十几个页面里找散落的假数据。
