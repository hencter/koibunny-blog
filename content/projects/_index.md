这里的项目有一个共同标准：**能跑起来，而且我知道它跑到什么程度**。
每个页面都带状态徽标和一份「现状」清单，把已完成和没做的分开写——
比把半成品说成产品有用。

`已发布` 表示代码已经在 GitHub 上，`整理中` 表示本地能跑、但还差清理与 LICENSE。
还有一批项目不适合开源（含密钥、含第三方代码、或本身就是别人的仓库），
判断过程写在[《E 盘开源体检》](/posts/open-source-audit/)里。
